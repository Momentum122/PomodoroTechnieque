# PomodoroTechnieque
 A Very lowkey timer made for the infamous pomodoro technique used to focus on one task for 25 minutes and tkaing a rest and then continuing again.

 # Features
 - It has three buttons 
 - Start Button : Starts the 25 minute timer 
 - Stop Button : Stops the timer if you cant do it 
 - Reset Timer button : Restarts the timer 
 - when timer ends displays Times Up! and automatically stops and resets the timer .
